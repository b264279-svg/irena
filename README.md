# NEON WARD

HTML、CSS、JavaScript だけで作られた、ブラウザで遊べる 2D サバイバルゲームです。

## 起動方法

このリポジトリのルートで次を実行してください。

```bash
npm start
```

起動後、ブラウザで [http://localhost:4173](http://localhost:4173) を開くとプレイできます。
終了するには、起動したターミナルで `Ctrl+C` を入力します。

## 操作

| キー | 操作 |
| --- | --- |
| `W` `A` `S` `D` / 矢印キー | 移動 |
| `Space` | 攻撃 |

敵を倒すとスコアが増え、100点ごとにウェーブが上がります。HP が 0 になるとゲームオーバーになり、画面のボタンからすぐにリスタートできます。

## 確認

```bash
npm run check
```
